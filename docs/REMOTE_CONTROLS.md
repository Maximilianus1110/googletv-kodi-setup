# 🎮 Fernbedienungs-Belegung (Streaming-Standard)

Die Steuerung in diesem Setup wurde speziell an das intuitive Verhalten moderner Streaming-Dienste (wie Netflix, Prime Video, Disney+) angepasst. Das Standard-Verhalten von Kodi, bei dem die Hoch/Runter-Tasten riesige 10-Minuten-Sprünge machten, wurde vollständig ersetzt.

---

## 1. Während der Video-Wiedergabe (Player)

| Taste | Aktion | Verhalten & Funktion |
| :--- | :--- | :--- |
| **Steuerkreuz Oben (▲)** | `OSD` | Blendet den **Zeitbalken (Timeline)**, Filmtitel, Spielzeit und Restlaufzeit ein. |
| **Steuerkreuz Unten (▼)** | `Playlist Drawer` | Öffnet die **Staffel-Episoden-Schublade (Playlist)** direkt im Player (wie bei Prime Video) zum schnellen Folgenwechsel. |
| **Steuerkreuz Links (◄)** | `StepBack` | Spult präzise **10 Sekunden zurück**. |
| **Steuerkreuz Rechts (►)** | `StepForward` | Spult präzise **10 Sekunden vor**. |
| **Auswahltaste (Mitte)** | `PlayPause` | Hält die Wiedergabe an (**Pause**) bzw. setzt sie fort (**Play**). |
| **Zurück-Taste (Back)** | `Close` / `Back` | Schließt die OSD-Infoanzeige bzw. die Episodenschublade, stoppt das Video bei wiederholtem Drücken. |
| **OSD-Button 🔄** | `Change Stream` | Öffnet mitten im Video den **Stream-Auswahldialog** (VAVOO Mirrors, VOE, Filemoon etc.) und setzt die Wiedergabe nahtlos an der aktuellen Sekunde fort. |

---

## 2. Im Hauptmenü & Seitenleiste (Arctic Fuse 2)

| Taste | Aktion | Verhalten |
| :--- | :--- | :--- |
| **Steuerkreuz Links (◄)** | `SideMenu` | Öffnet die linke Navigationsleiste (Filme, Serien, Live-TV, YouTube). |
| **Steuerkreuz Rechts (►)** | `HomeMenu` | Navigiert in die Startseiten-Widgets & Film-/Serien-Karussells. |
| **Steuerkreuz Oben / Unten** | `Navigate` | Wechselt zwischen den Reihen (Weiterschauen, Nächste Episoden, Trends). |
| **Auswahltaste (Mitte)** | `Select` | Öffnet den ausgewählten Film bzw. die Serie und startet den automatischen Stream-Scraper. |
| **Zurück-Taste (Back)** | `Back` | Geht eine Ebene zurück. |

---

## 3. 🔒 Geheimer +18 Schnellzugriff

* **Tastenkombination:** Halte die **Zurück-Taste für ca. 5 Sekunden gedrückt** (Long-Press Back).
* **Verhalten:** Es öffnet sich direkt das PIN-Eingabefenster für die Erwachsenen-Mediathek (`AdultHideout`).
* **PIN:** `0000` (4 Nullen).
